# HackerTube data (fork)

Copy of the public data export from [HackerTube](https://hackertube.org), the YouTube-style site of videos recommended on Hacker News, built by Claude Opus 5.5 and prompted by [@karpathy](https://x.com/karpathy).

Downloaded on 2026-11-02 from https://hackertube.org/download/hackertube-data.zip (data generated 2026-10-31: 6,454 videos, 39,834 mentions).

Read `DATA.md` first: it explains how the files fit together and is written for AI coding agents.
